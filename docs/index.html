FAQ

Common questions

Do I need to be a developer to use Tappy?

Tappy is a CLI tool, so basic terminal familiarity helps. But the core workflow is just two commands: tappy forge "what you want" and tappy run site name. If you can type in a terminal, you can use Tappy. The 185+ pre-built taps work with zero setup.

Is my data safe? What does Tappy access?

Tappy programs run in a sandboxed Worker with zero permissions — no filesystem, no network, no subprocess access. The Chrome Extension only activates when you forge (observe a page). Your data never leaves your machine. Everything is local and open source.

What happens when a website changes its layout?

Tappy's doctor runs health checks against declared contracts. When a tap breaks, tappy doctor --auto diagnoses the issue (changed selectors, moved APIs, new auth) and re-forges the program automatically. Most fixes happen without you noticing.

How is this different from Zapier or n8n?

Zapier charges per task ($0.01–$0.05 each). At scale, that's $40K+/year. n8n is free but needs DevOps to self-host. Tappy has zero per-execution cost — AI runs once to create the program, then it runs forever for free. No servers, no billing surprises.

Can I use my own AI key instead of paying for Pro?

Yes. tappy config set ai.key sk-ant-xxx lets you bring your own Claude or OpenAI key. The Hacker plan ($9/mo) unlocks forge with your own key. The Pro plan ($29/mo) includes AI — no key needed.

Do I own the programs Tappy creates?

Yes. Every .tap.js file is a plain JavaScript program on your disk. No lock-in, no cloud dependency. Cancel your subscription and your programs keep running forever. You can even read and edit them by hand.
