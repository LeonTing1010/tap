FAQ

Common questions

Do I need to be a developer to use Tappy?

Tappy is a CLI tool, so basic terminal familiarity helps. The core workflow is just two commands: tappy forge "what you want" and tappy run site name. The 185+ pre-built taps work with zero setup.

Is my data safe? What does Tappy access?

Tappy programs run in a sandboxed Worker with zero permissions — no filesystem, no network, no subprocess access. The Chrome Extension only activates when you forge. Your data never leaves your machine.

What happens when a website changes?

tappy doctor --auto runs health checks against declared contracts. When a tap breaks, it diagnoses the issue and re-forges the program automatically. Most fixes happen without you noticing.

How is this different from Zapier or n8n?

Zapier charges per task ($0.01–$0.05 each). At scale, that's $40K+/year. n8n is free but needs DevOps. Tappy has zero per-execution cost — AI runs once, program runs forever for free.

Can I use my own AI key?

Yes. tappy config set ai.key sk-ant-xxx lets you bring your own Claude or OpenAI key. The Hacker plan unlocks forge with your own key. Pro includes AI built-in.

Do I own the programs Tappy creates?

Yes. Every .tap.js file is a plain JavaScript program on your disk. No lock-in, no cloud dependency. Cancel and your programs keep running forever.
