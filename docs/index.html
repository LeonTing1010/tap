And there's a second problem

Your scraper is broken right now. You just don't know it yet.

Websites change their DOM. APIs shift. Selectors silently die. Browser-Use keeps running — it just returns empty arrays. Nobody notices for days.

Self-healing

Tap's doctor catches breakage within the hour.

After every execution, tap doctor runs health contracts. Fingerprint diff (semantic, ARIA-based — survives CSS-in-JS rebuilds) tells you exactly what changed — not just "0 rows," but the precise selector that disappeared and the API schema that shifted. --auto packages everything an AI needs to fix it.

$ tap doctor --auto github trending
✗ selector h2.repo-name — gone since last run
⚠ fingerprint diff: ↑ 3 structural changes
✓ heal bundle ready — current code + git history + page snapshot
✓ Tap — you (or your agent) know within the hour, with the exact diff
✗ Browser-Use — empty arrays, three days of garbage data
Deterministic

100% consistent results. Not 60–95%.

Browser-Use and Stagehand re-interpret the page on every run — the same page, the same task, different results each time. A compiled tap is deterministic code: the same input always produces the same output.

FAQ

Common questions

How is Tap different from Browser Use or Stagehand?
Browser Use and Stagehand call AI on every run — $0.50–$2.00 per execution, 60–95% reliability. Tap uses AI once to create a deterministic program, then runs it forever at $0. More importantly, when websites change, tap doctor detects breakage and fingerprint diff tells you exactly what changed — not just "0 rows" but "the h2 a selector is gone." Tap is infrastructure, not just a tool.
What happens when a website changes?
tap doctor --auto detects breakage via health contracts and packages everything an AI needs to fix it: the current tap source, fingerprint diff (which selectors disappeared, which API schemas shifted), the last 3 commits to the tap, and a fresh page inspection. Free users hand that bundle to their AI (Claude Code, Cursor, or tap forge BYOK). Pro users put it on cron and Tap's built-in AI patches and ships the fix overnight, with Slack alerts on success.
Can I use my own AI key?
Yes. tap config set ai.key sk-ant-xxx lets you bring your own Claude or OpenAI key. Works with any OpenAI-compatible provider (DeepSeek, Ollama, etc.).
How is this different from Zapier or n8n?
Zapier charges per task ($0.01–$0.05 each). At scale, that's $40K+/year. Tap has zero per-execution cost — AI runs once, program runs forever for free.
Do I own the programs Tap creates?
Yes. Every .tap.js file is a plain JavaScript program on your disk. No lock-in, no cloud dependency. Cancel and your programs keep running forever.
Does Tap work offline?
Programs run locally with zero AI calls — no internet needed for execution. You only need connectivity when forging a new program (AI compilation) or when the program accesses a website. The programs themselves are plain JavaScript on your disk.
Is my data safe?
Tap programs run in a sandboxed Worker with zero permissions — no filesystem, no network, no subprocess access. Your data never leaves your machine.
Is web scraping with Tap legal?
Tap prioritizes tap.fetch() (API calls) over DOM scraping. APIs are structured, stable, and carry less legal risk than screen-scraping. When APIs aren't available, Tap uses standard browser rendering — the same way a human would access the page. Always check a site's terms of service.
Do I need to be a developer?
Basic terminal familiarity helps. The core workflow is two commands: tap forge "what you want" and tap site name. 300+ pre-built taps work with zero setup.
