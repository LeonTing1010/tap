The Core Idea

Self-distillation for interfaces.

AI agents spend tokens on every interface interaction — understanding pages, clicking buttons, extracting data. That's a prompt: expensive, non-deterministic, and fragile at scale.


Tap is self-distillation applied to interfaces. AI observes an interface once, distills its understanding into a deterministic .tap.js program, and every subsequent run is pure execution — zero AI, zero cost, zero variance.


Every successful forge makes the next one faster. Community skills compound: 200+ forged programs mean your agent starts with knowledge of 200+ interfaces, no forging needed. The protocol gets smarter without getting more expensive.

Common questions

Do I need to be a developer?

Basic terminal familiarity helps. The core workflow is two commands: tap forge "what you want" and tap site name. 200+ pre-built taps work with zero setup.

Is my data safe?

Tap programs run in a sandboxed Worker with zero permissions — no filesystem, no network, no subprocess access. Your data never leaves your machine.

What happens when a website changes?

tap doctor detects breakage via health contracts. When a tap breaks, it diagnoses the issue. Most fixes happen with one forge command.

How is this different from Zapier or n8n?

Zapier charges per task ($0.01–$0.05 each). At scale, that's $40K+/year. Tap has zero per-execution cost — AI runs once, program runs forever for free.

Can I use my own AI key?

Yes. tap config set ai.key sk-ant-xxx lets you bring your own Claude or OpenAI key. Works with any OpenAI-compatible provider (DeepSeek, Ollama, etc.).

Do I own the programs Tap creates?

Yes. Every .tap.js file is a plain JavaScript program on your disk. No lock-in, no cloud dependency. Cancel and your programs keep running forever.
