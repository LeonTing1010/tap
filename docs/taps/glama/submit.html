What it does

Submit an MCP server to Glama directory

How to call it

From your terminal once Tap is installed:

tap run glama/submit

Or from an MCP-aware client (Claude Code, Cursor, Cline) — the exact same plan runs deterministically without re-inferring the site structure:

tap.run({ site: "glama", name: "submit" })

Why compile it once

This plan was forged once — the AI read glama, picked stable structural addresses, and saved them to a .tap.json. Every replay since then has used zero LLM tokens. When glama ships a site change that breaks the extraction, tap doctor surfaces it before your data goes stale.
