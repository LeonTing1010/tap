What it does

Create a GitHub issue via API

How to call it

From your terminal once Tap is installed:

tap run github/create-issue

Or from an MCP-aware client (Claude Code, Cursor, Cline) — the exact same plan runs deterministically without re-inferring the site structure:

tap.run({ site: "github", name: "create-issue" })

Why compile it once

This plan was forged once — the AI read github, picked stable structural addresses, and saved them to a .tap.json. Every replay since then has used zero LLM tokens. When github ships a site change that breaks the extraction, tap doctor surfaces it before your data goes stale.
