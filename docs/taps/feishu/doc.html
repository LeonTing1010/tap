What it does

Read current Feishu doc full text (block_map + TOC fallback)

How to call it

From your terminal once Tap is installed:

tap run feishu/doc

Or from an MCP-aware client (Claude Code, Cursor, Cline) — the exact same plan runs deterministically without re-inferring the site structure:

tap.run({ site: "feishu", name: "doc" })

Why compile it once

This plan was forged once — the AI read feishu, picked stable structural addresses, and saved them to a .tap.json. Every replay since then has used zero LLM tokens. When feishu ships a site change that breaks the extraction, tap doctor surfaces it before your data goes stale.
