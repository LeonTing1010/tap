One more step to activate

The Tap Chrome extension is a runtime — it needs the Tap CLI daemon running on your machine to receive commands.

1
Install the Tap CLI

The CLI starts the local daemon that the extension connects to. Choose your preferred install method:

$ npx @taprun/cli list click to copy
or install globally
$ npm install -g @taprun/cli click to copy
$ curl -fsSL taprun.dev/install.sh | sh click to copy
$ curl -fsSL taprun.dev/install.sh | sh click to copy
2
Start the daemon

Run this once — it starts the local HTTP broker that the extension connects to on port 9333.

$ tap daemon click to copy
The CLI daemon starts automatically when you run any tap command. You don't need to keep a terminal open.
3
Check the connection

Run any tap command — the extension badge should turn green (or disappear) once the daemon is reachable.

$ tap list # lists available taps — confirms daemon is running click to copy
Once connected, click the Tap icon in your toolbar — it will show Tap — connected and the red badge will clear.
