Getting Started

From install to your first automation in 5 minutes.

1 Install Tappy

# macOS / Linux
curl -fsSL https://taprun.dev/install.sh | sh

# Verify
tap --version
tap 0.5.0

This installs the tap CLI binary and the Chrome Extension files to ~/.tap/.

2 Install Chrome Extension

The extension lets Tappy observe web pages during forge (one-time setup).

  1. Open Chrome and go to chrome://extensions/
  2. Enable Developer mode (top right toggle)
  3. Click Load unpacked
  4. Select the folder: ~/.tap/extension/
  5. Pin the Tap icon to your toolbar
Tip: If the icon shows a red !, the daemon isn't running. Run tap daemon in another terminal.

5 Forge Your First Tap

Open the target website in Chrome, then:

# Describe what you want in plain English
tappy forge "scrape the trending topics from Google Trends"

6 Set Up Self-Healing

Check if your taps are healthy. Fix broken ones automatically:

# Check all your taps
tap doctor

# Auto-heal broken taps (Hacker/Pro)
tap doctor --auto
🔧 Auto-heal: 1 tap(s) with diagnostics
  google/trends:
    issue: min_rows: expected 5, got 0
    fix: selector changed, re-forging...
✔ Healed google/trends

7 Schedule Recurring Runs

Use cron, launchd, or any scheduler. Tappy is just a CLI:

# Run every morning at 9am
crontab -e
0 9 * * * tap run google trends >> ~/trends.log

# Or use tap watch for change detection
tap watch google trends --every 1h
