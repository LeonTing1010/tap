Saved taps run in this browser. Credentials stay on your machine.

Setup required

Register the native messaging manifest:

tap bridge setup --extension-id …

One-time. Connects this Chrome extension to the local Tap daemon.

Don't have Tap installed?
Bridge not running

Start it:

tap bridge start

If the daemon is already running, the native host may have crashed — check host.log next to the tap binary.

Chrome blocked the host

One of:

  • Host crashed ≥5 times — Chrome lockout active ~10 min. Restart Chrome to clear.
  • Manifest allowed_origins doesn't include this extension. Re-run setup.
