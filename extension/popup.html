Setup required

Register the native messaging manifest:

tap bridge setup

One-time. The extension ID is pinned in the manifest, so the command takes no flag — copy & run.

Don't have Tap installed?
Bridge not running

Re-run setup (idempotent — writes the service if missing):

tap bridge setup

Then follow the printed launchctl bootstrap (macOS) or systemctl --user enable --now (Linux) line to load the service. If the service is already loaded, the host may have crashed — check host.log next to the tap binary.
