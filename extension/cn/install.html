Taprun 国内安装引导

Chrome 网上应用店在中国大陆不可用，但 Taprun 的扩展和引擎都能在本地正常运行。按下面三步手动安装即可，全程不依赖任何被屏蔽的站点。

为什么不用商店？ Chrome 网上应用店与官网 taprun.dev 在中国大陆均不可达，因此本页把安装入口与下载都改到了国内可访问的通道：扩展包走 GitHub 代理下载，引擎走 npm 国内镜像安装。

安装步骤

1

下载并加载扩展

扩展不能从商店安装，需手动「加载已解压的扩展」。

a. 下载扩展包（走 GitHub 代理，国内可访问）：

https://ghproxy.com/https://github.com/LeonTing1010/tap/releases/latest/download/taprun-chrome-extension.zip

b. 解压到任意本地目录。

c. 打开 chrome://extensions，右上角打开「开发者模式」，点「加载已解压的扩展」，选择刚解压的目录。

工具栏出现 Taprun 图标即成功。

2

安装本地引擎（npm 国内镜像）

引擎通过 npm 镜像安装，无需访问官网：

# 一步完成：安装二进制 + 注册 Chrome 原生通讯清单（无需任何 flag）
npx --registry https://registry.npmmirror.com -y @taprun/cli embed claude-code

或用 Homebrew（国内可换清华/中科大镜像源）：

brew install LeonTing1010/tap/taprun
tap bridge setup   # 注册原生通讯清单（无 daemon、无端口）

扩展 ID 已固定在清单的 "key" 字段，tap bridge setup 无需任何参数。

3

验证连接

点击工具栏 Taprun 图标，应显示 Connected to local bridge。引擎只在 Chrome 打开时运行，关掉所有 Chrome 窗口即停止。

可选：让 AI 助手调用 Taprun（Claude Code 最简，无需终端）：

/plugin marketplace add LeonTing1010/taprun
/plugin install tap@taprun
/reload-plugins

故障排查

扩展加载了但显示「Bridge not running」
  • 运行 which tap：若为空，说明引擎没装进 PATH，回到步骤 2 重装。
  • 若打印了路径，打开同目录下的 host.log 看启动崩溃原因。
  • 常见原因：原生通讯清单里的扩展 ID 过期（运行 tap bridge setup 重写），或 Chrome 防 DoS 锁定（完全退出再重开 Chrome 清除）。
显示「Chrome blocked the host」
  • 运行 tap bridge setup 重写原生通讯清单。
  • 完全退出 Chrome（macOS ⌘Q）再重开，清除防 DoS 锁定。
  • 仍失败可运行 tap bridge status 看哪一侧配置错误。
显示「Bridge down」/ 未知错误
  • 运行诊断：tap bridge status（检查 CLI 安装、socket、原生清单）。
  • 若清单缺失：tap bridge setup。
  • 引擎未运行：在 chrome://extensions 重新加载 Taprun 扩展，浏览器会按需拉起宿主进程，没有独立 daemon 要启动。
